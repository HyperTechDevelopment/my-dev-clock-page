# my-dev-clock-page

Site de apresentação do [my-dev-clock](https://github.com/HyperTechDevelopment/My-dev-clock) —
relógio de terminal para Windows em Rust. Página estática, sem dependências:
só HTML, CSS e JavaScript vanilla.

## Ver localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```powershell
python -m http.server 8000
```

## Publicação

Publicado via GitHub Pages a partir da branch `main` (raiz).
